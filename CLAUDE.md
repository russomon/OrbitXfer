# Claude Guidance

This repository is shared between Claude Code, Codex, and multiple local computers through GitHub.

Read these files first when resuming work:

- `README.md`
- `AGENTS.md`
- `CURRENT_WORK.md`
- `NEXT_STEPS.md`
- `DECISIONS.md`
- `SHARED_CODING_WORKFLOW.md`
- `RELEASES.md` when the task touches releases

Follow the rules in `AGENTS.md`. In particular, keep OrbitXfer as the active successor to `orelay`, keep the Rust CLI as the transfer engine behind the Tauri GUI sidecar, and keep signing/notarization credentials out of Git.

Before switching to another computer or agent, update the handoff files with what changed, what was validated, and the exact next step, then commit and push.
